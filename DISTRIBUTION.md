# Public distribution

This repository contains the current skill, complete example concepts, visual previews, local reconstruction sources, and original generation/reference lineage. README and the site home are presentation-focused entry points for this distribution.

Large ZIP handoffs are hosted on the `showcase-2026-10-14` GitHub Release. `download-manifest.json` records each original relative ZIP path, release URL, byte count and SHA-256. Gallery download links were adapted to those URLs; the ZIP bytes and hash-bound project evidence were preserved. Core workflow files match the local skill source. The showcase material is illustrative and retains its recorded draft/feedback status.

Historical generation records can contain the original local input/output paths and execution identifiers. Those fields document past execution; they are not portable live dependencies. Use the project-relative concept, component, source and renderer paths to reload the delivered examples. Installed fonts and external PPTX backends are not bundled.

`.gitattributes` preserves raw file bytes, including text line endings, so a checkout does not invalidate evidence hashes. Public distribution excludes caches, local backups, internal root reports, and superseded experimental PPTX copies. The disposable copy used by the current editability evidence is retained.

The complete industry and competition sets end at concept mode. The three-page PPTX is an independent reconstruction experiment; publication does not change its user-acceptance or formal-assembly status.
