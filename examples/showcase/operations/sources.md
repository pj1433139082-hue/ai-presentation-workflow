# 逐页来源与数据边界

## 样稿定位

`deck-草稿.pptx` 是委托式本地展示草稿，使用“示例工厂 A”和“Q3 示例周期”作为虚构占位。所有数字、计划值、实际值和归因比例均由样稿作者编造，不来自任何公司、财务披露、订单、MES/ERP、质量系统或设备记录。没有外部事实主张，也不宣称真实经营改善。

此稿不是完整 human G1–G5 生产链认证，不是人类批准或生产准入记录。页面渲染与验收由主智能体另行记录。

## 数值复算

- 产量达成率：12,400 ÷ 13,000 = 95.4%。
- 产量差距：(12,400 − 13,000) ÷ 13,000 ≈ −4.6%。
- 准时交付率：94% − 96% = −2 个百分点。
- 一次合格率：96.8% − 97.5% = −0.7 个百分点。
- 非计划停机率：3.2% − 2.5% = +0.7 个百分点。
- 单位能耗相对计划增幅：(8.1 − 7.8) ÷ 7.8 ≈ +3.8%。

## 素材与构建

- `assets/factory-hall.png`、`assets/pump-motor.png`：使用内置图像生成工具生成的透明 PNG 单体插图，不是现场照片或设备证据。
- `build_deck.py` 使用 Python 3.13 环境中的 `python-pptx` 生成 16:9 PPTX。KPI 卡、条形图、文本和计划卡由 PowerPoint 原生对象构成，插图作为单独图片嵌入。
- 商业事实来源：无。所有经营数值与根因占比均为虚构。
