# 三页全页素材与独立重建试验

主入口 index.html；project/ 为 APW assets + full-slide 全页合同的可再检查证据。ZIP 内 独立素材/ 有66份直接可用源文件：13张PNG、36个SVG及17份普通文字JSON，覆盖背景、设备、字形、阴影反射、箭头、管线和残余装饰。项目证据按原相对路径保留地图、渲染器与源。

PPTX另为独立重建试验，不能称作完成APW assembly合同或用户视觉验收。实际PowerPoint渲染与编辑实验记录位于proof/independent-pptx/。构建时的地图/素材清单快照在input-contract/；构建后新增QA元数据，场景与素材字节保持不变，详见proof-evidence.json的post_build_asset_review。

普通字体是本机系统字体近似，未嵌入/分发字体软件；金属字形为透明PNG。生成式设备、膜片水流和原生管线材质与原概念有差异，不保证无损或逐像素一致。图库有逐层开关和浅/深底检查；科研及工业内容为示例。历史旧指定素材包保留。
