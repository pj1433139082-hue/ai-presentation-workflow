# Concept revision provenance

This archive preserves actual image bytes, prompts, and tool records for the S04 and S05 revisions before package export.

- S04 retains attempt-01 image/prompt/tool record and the revision-02 image/prompt/tool record. The revision-02 record identifies the prior attempt and the reason for the edit.
- S05 retains the first image and initial prompt, plus the revised image/prompt/tool record. The revised record binds the first output path/hash and edit reason; a separate first-attempt tool record was not present, so none is fabricated.
- `revision-history-manifest.json` lists exact file hashes and the provenance chain.
