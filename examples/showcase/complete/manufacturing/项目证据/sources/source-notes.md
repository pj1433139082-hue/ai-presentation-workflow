# 制造业余热回收：内容示例与事实边界

本项目是关于制造业余热回用机制的虚构展示稿。没有真实工厂现场、过程参数、设备资料、工程计算、施工设计、安全评审、节能量或投资回报数据。

## 讨论示例

- 主题：余热来源与用热需求的匹配思路。
- 概念路径：加热 → 生产 → 排热 → 换热 → 回用 → 加热。此路径只是一般机制示意，不说明任一特定现场可以这样连接。
- 讨论提问：识别潜在热源和用热点，核对供需时间关系与连接条件，再由具备相应职责的专业人员复核。
- 方案建议：先收集现场资料，检查安全、接口和运维条件；是否进入试点需基于真实数据和专业评审。
- 当前限制：没有温度、压力、流量、时长、设备规格、效率、成本、收益或性能保证。
