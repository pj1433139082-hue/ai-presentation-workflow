# 拾集：内容来源与事实边界

本展示是虚构校园旧物循环服务“拾集”的创新创业路演示例，只用于视觉与叙事概念展示，不是参赛材料、正式项目或真实服务。没有真实学校、用户、访谈、市场调研、客户、营收、合作、试点、团队成员、奖项、许可或合规结论。场景均为概念情境，人物与画面为 AI 示意，不是实地证据。

## 方案设定（全部为示例构想）

- 服务对象情境：离校同学希望省事处理仍可用的台灯、收纳箱等物品；新入学同学希望就近找到状态清楚、价格合适的基础用品。该描述是情境推演，不是用户研究结论。
- 服务机制构想：登记物品与照片 → 清洁并标注状态 → 需求匹配与预约 → 校内当面交接。流程未上线、未执行、未验证。
- 差异化假设：统一描述物品状态、在校内就近流转、为交接留下记录。它们是拟测试的服务设计点，不代表已有技术或实际竞争优势。
- 试点设计示例：假设选择一栋宿舍楼、四周、最多登记40件物品；建议观察成功交接数、匹配时长、人工用时与参与意愿。试点没有发生，数字是方案范围而非结果。
- 收支示例：假设单月完成30次交接、每次收取5元服务费，收入30×5=150元；假设耗材90元、运送120元、运营工时折算240元，总成本450元；示例差额150−450=−300元。金额和次数均为演示用假设，不是市场报价、收费政策或真实经营数据。
- 团队分工示例：协调、运营、产品记录、传播四类任务；未对应真实成员。发展计划按先验证流程、再核算单位经济、最后决定是否扩点的顺序设想，均未实施。
- 本展示不引用具体赛事徽章、评审规则或资格判断，不表示符合任何竞赛要求。
