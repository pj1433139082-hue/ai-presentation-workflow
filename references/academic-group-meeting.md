# 科研组会：整页科学图解预设

用于论文精读、研究生学术组会和研究进展汇报。用户未另给视觉方向时，可沿用本预设的已认可参考；用户选择其他方向时服从当次 brief。这里固定制作过程和可核查的输入，不将某篇论文的 11 页、配方、结果或蓝色流程图强加给其他课题。

**默认主展示风格已确认。** 用户查看同论文独立复现的完整 11 页后明确回复：“没问题这个 这个可以作为 ppt 的主要展示风格 很完美”。科研组会、论文精读和科研进展类 PPT 默认采用这里的完整科学图解语言；不必每次重新探索风格，除非用户提出新方向。复用实际参考与制作过程，按新内容组织布局；此认可不覆盖尚未制作的独立素材或最终 PPTX。

## 已验证的基线

[整套已认可概念](../examples/academic-group-meeting/index.html)与[模板包清单](../examples/academic-group-meeting/manifest.json)保留完整概念、S04 实际视觉参考、逐页原始生成及局部编辑提示词、对应输入输出和原文图件。用户于 2026-10-18 回复“这次很不错……可以作为组会汇报 ppt 的模版”。接受范围为该版 11 页完整概念；没有已经接受的独立素材或最终 PPTX。

读取清单后查看实际 S04 和适合当前页角色的实例。仅把已认可页面用于本次风格参考，不把实例中的材料、模型、数字、机制或外部测试方案当作新论文事实。图中球色以本页图例定义，跨页表示同一实体时在本项目明确颜色映射。

**复现的是过程与视觉水平，生成图不保证逐像素复现。** 记录实际模型/工具、提示词、输入图片及哈希、每次输出和选择理由；当前内置工具没有提供的 seed、尺寸参数或模型参数不要虚构。保留已认可图像可精确复用风格基准和历史概念，新论文图形仍需实际检查。

## 从资料到完整概念

1. **先形成证据与讲述计划。** 读取论文全文、主要图表及可取得的补充材料。把研究问题、既有工作、方法、关键结果、局限、下一步写成有来源的逐页主张，并分配讲述秒数。论文精读与自己进展的证据边界不同；页数由任务和讲述需要决定，不能用一张“代表页”交代整套。每条重要量值留来源页/图、单位、对象与条件。
2. **确定实际风格参考。** 默认查看包内 S04，再用它约束每一页的图形质感、海军蓝文字、白底、浅蓝分区、克制的金色强调和信息密度。按角色选择问题地图、比较、方法流、证据链、实验循环等构图；不要求每页两行流程，不统一套卡片。用户已认可某个实际页面时保留其原文件和哈希。新领域不凭空画材料晶格或生物结构来占位。
3. **逐页设计完整科研图解。** APW 负责全套叙事；需要科学关系时采用 SFW 的图意、关系和整图审查。不是仅把方法图交给 SFW、其余做普通文字页。先写当前页确切文案、已核实事实和关系，再用内置 image_gen 生成整页概念，并实际附上已查看的风格参考图。完整概念阶段不受以后 PPTX 对象模型、透明切件或 native 图形实现能力约束。
4. **原始证据面板独立保真。** 已发表图表、显微照片、实测曲线与数据不是生成模型的补绘对象。结果页可先生成带干净留白的完整概念，查看实际输出后再按真实窗口位置嵌入原图，保持比例、不裁掉坐标或图例；也可采用同样科学图解语言的混合布局。不要盲用提示词里请求的坐标：生成窗口实际位置可能不同。保存源图字节和哈希，记录裁剪来源及最终嵌入矩形；整页合入后再查看可读性和遮挡。
5. **局部提示词修正。** 看过目标图后，对错字、维度、实体、因果关系、箭头端点或拥挤区域逐次局部编辑，附真实目标图，说明只改变什么、应保留什么，保存每次实际输入/输出。只修改提示词不等于图已经修好；必须看新图。参考案例的要点是 20 维输入→2 维嵌入→20 维重建、实验回填预测模型、OER 不写成氧还原，以及原图留白窗口不被改坏，不能原样套入别的论文。
6. **审阅完整当前批次。** 检查每页科学关系、正文和图例，再看整套联系表：标题层级、配色语义、图形质感、页脚、信息密度及转场是否协调。真实结果面板合入后查看整页原尺寸，检查单位/条件、来源、图例与绘图区。示意分布不声称真实分群，虚构谱峰不当作检测结果，内部拟合不冒充独立外部性能，热力学自由能不冒充动力学能垒。不要为统一风格重画真实证据。
7. **整批展示与反馈。** 提供全部计划页、原尺寸入口、整套总览、讲述提纲、提示词与版本记录。按[共用反馈协议](stage-feedback.md)询问本轮整批是否调整并等待。单页认可只绑定单页；用户认可整套概念后才进入已选素材/组装范围。素材与最终 PPTX 仍各有整批反馈；本预设不增加逐对象审批。

## 新项目启动与证据文件

下面的启动器复用 APW 的 init_showcase，为新建本地学术草稿写入真实项目路线与交付模式，同时附风格参考、参数化提示词和待填角色提纲。它不生成图、不复制旧论文结果、不等于 APW/G4 检查通过。已有项目仍拒绝覆盖；正式生产项目按原契约继续，不用此新建草稿入口转换路线。

```powershell
python scripts/academic_group_meeting.py init OUTPUT --paper-title "当前论文题名" --minutes 15 --mode concept
python scripts/academic_group_meeting.py init OTHER_OUTPUT --title "当前研究进展" --intent progress --minutes 12 --mode concept
python scripts/academic_group_meeting.py verify-template
```

`--mode assets|assembly` 仅在用户要求对应交付时使用。已有项目直接按其契约继续，不用 init 覆盖。完成初始化后填写 `brief.json`、`storyboard.json` 和 `sources/evidence-map.json`；生成图仍由 agent 实际调用内置 image_gen。检查 `prompt-template.md` 中的内容槽位，不把槽位文本原样送去生成。

每个新项目至少可定位：论文/数据来源、实际参考图及哈希、有序页 ID 和时间、逐页完整提示词与真实工具输出、局部编辑父子关系、最终概念及哈希、原始证据面板和嵌入位置、整套审阅与当次用户反馈。工具成功、空脚手架、文件计数和子 agent 认可均不能填作用户视觉验收。

合入真实证据之后如需继续生成式改图，回到未含原始证据的概念底图进行编辑，再重新嵌入来源原图；不要把带原始曲线、显微证据或数据表的合成整页交给 image_gen 编辑。提示词写“保留原图”不能保证未请求区域不变。原图、底图和最终合成保持分层记录与哈希。

裁切也要实际验图：对照 PDF 整页确认裁切的轴标题、刻度、单位、图例完整且不夹带邻图。记录 PDF 页号、点坐标裁切框和渲染倍率；若从截图取像素坐标，先核对实际像素尺寸与缩放，不按工具缩小后的预览估坐标。源文件哈希相符只说明所选裁切未变，不能证明裁切本身完整。

来源表用稳定 source_id 连接各页 source_refs，核实后补 DOI/URL 与完整书目信息。每页可见脚注至少有作者/年份短引用及图号；完整来源随包携带，避免单页外发后只剩不明所指的“主文 Fig.2”。

页码只放一处，来源行不重复页码。完整批次复现中出现过缩写错配和重复页码，因此整套审阅要逐项对照“实体—量值—条件”及来源行；仅看整体风格相似不能通过内容检查。

## 复现检查

让不带本次制作历史的 agent 从新版技能、当前论文和干净目录开始，真实产出新的完整概念批次。可复用包内风格参考，不允许把已完成的整页当新输出或将旧论文数值当新研究的默认值。记录其实际输入、调用、修订、原图保真和阶段停点；主 agent 对照真实结果检查。若只做初始化或三页抽样，明确该范围，不称整套生成已经复现。量化检查和视觉审阅分开；生成时间、调用次数是当次记录，不是固定流程或质量保证。
